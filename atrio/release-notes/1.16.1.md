The install button shows how far a Steam download goes, with its speed, and fills up as it advances.

- **Real progress for Steam.** Atrio read the progress from the game's file in Steam, which Steam only updates at the end, so the button said "Installing" with no number for the whole download. Now it asks Steam's own list of downloads, the one its phone app uses, and shows "Installing 37 % · 24 MB/s", or "Paused" when Steam stops it. If Steam doesn't answer, it goes back to the file, as before.
- **The button fills up.** The Play button of the game page is drawn as a progress bar while a game installs, in the seven Atrio themes. Third-party themes keep their own button.
- Full screen mode shows the speed and the pause too.
