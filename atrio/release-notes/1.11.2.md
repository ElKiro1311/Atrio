Atrio recovers by itself when the graphics driver restarts.

- **Graphics driver restart.** When a game hangs the graphics card and Windows restarts its driver, Atrio can no longer draw itself. Before, that opened error windows one on top of another. Now Atrio closes and opens again by itself a few seconds later, in the same mode. If it fails again right after opening, the usual error window comes up.
- **A single error notice.** If several errors arrive in a row, only the first one is handled.
- **itch.io without its app installed** no longer leaves errors in the log, just a one-line warning.
- New tests for the "Update pending" notice and for the restart. 315 tests.
