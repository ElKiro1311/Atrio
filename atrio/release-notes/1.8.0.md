Couch Mode has its own browser to use with the controller, and its Home marks the game you have open.

- **Couch Mode browser.** Links open inside Atrio, in full screen, without asking whether you want to leave. The left stick moves a pointer and A clicks. The right stick scrolls the page and B goes back or closes. X types into the selected field, Y goes to an address or searches, Menu acts as Enter, LT and RT change the zoom, and View closes. A mouse works too.
- **Guides and links for the game.** Each game's options have "Search for a guide" and its links (store, wiki…), which open in that browser.
- **The browser in Couch Mode's main menu**, to look up whatever you want.
- **The open game on Home.** The cover of the game that's open carries "● Running", like the desktop list, even if you opened it outside Atrio. When you select it, the button below is "Back to the game".
- The browser shares its sessions with the desktop one: if you already signed in to a website, you stay signed in. If you chose another browser for links in Settings, that one is still used.

El Modo Sofá tiene navegador propio para usarlo con el mando, y su Inicio marca el juego que tienes abierto.

- **Navegador del Modo Sofá.** Los enlaces se abren dentro de Atrio, en pantalla completa, sin preguntar si sales. El stick izquierdo mueve un puntero y A pulsa. El stick derecho desplaza la página y B vuelve atrás o cierra. X escribe en el campo elegido, Y va a una dirección o busca, Menú hace de Intro, LT y RT cambian el zoom, y Vista cierra. Un ratón también funciona.
- **Guías y enlaces del juego.** En las opciones de cada juego hay «Buscar una guía» y sus enlaces (tienda, wiki…), que se abren en ese navegador.
- **Navegador en el menú principal** del Modo Sofá, para buscar lo que quieras.
- **Juego abierto en el Inicio.** La portada del juego que está abierto lleva «● En ejecución», como la lista del escritorio, aunque lo abrieras fuera de Atrio. Al elegirlo, el botón de abajo es «Volver al juego».
- El navegador comparte las sesiones con el del escritorio: si ya entraste en una web, sigues dentro. Si en Ajustes elegiste otro navegador para los enlaces, se sigue usando ese.
