Versions are now called x.y.z-beta.

- Atrio's version is shown with its phase: **About**, the new-version notice and the what's-new window say **1.12.2-beta**. "beta" means that all of Atrio can be used and that it's still being tested and extended.
- New versions are published with their phase (**1.12.3-beta**, …) and Atrio already understands them. This one still comes out as 1.12.2, without the phase, so that earlier copies, which only understand the number, can find it; earlier versions already go by that name on GitHub (**1.12.1-beta**, …).
- Nothing else changes.
