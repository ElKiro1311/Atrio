Ubisoft Connect, from start to finish.

- **It no longer takes a game as installed too soon.** Ubisoft registers the game as soon as it starts downloading, and Atrio showed "Play" with the download half done. Now it waits until every file is there.
- **It presses nothing after the license.** When the download ends, Ubisoft's window shows the play button right where the continue button was. Atrio reads in Ubisoft's log when the download starts and from then on doesn't touch the window.
- **It no longer gets stuck on the first page.** Atrio recognized the button by a point that sometimes fell on a letter. Now it looks above the text.
- **If you close Ubisoft's window without installing**, the game goes back to "Install" instead of staying at "Installing".
- **When you accept the license yourself**, Atrio goes back to "Installing" as soon as the download starts and minimizes Ubisoft.
