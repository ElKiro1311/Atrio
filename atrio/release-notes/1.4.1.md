GOG games install from Atrio too, even without GOG Galaxy.

- **Without GOG Galaxy:** Atrio downloads the game's offline installer with the percentage on the button, checks that it arrived intact and opens it. Before, it only took you to your account's website. You need to be signed in to GOG in Atrio's browser.
- **The rest is up to Windows and the installer:** Windows asks for permission, and the installer shows its terms unless you've turned on the option to accept them. If you have, it installs by itself.
- With GOG Galaxy installed, everything stays as before.
